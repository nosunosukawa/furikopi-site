ならべコピ プライバシーポリシー

1. 開発者が収集する情報

ならべコピ（以下「本アプリ」）の開発者は、利用者の個人情報を一切収集しません。 本アプリには開発者のサーバーが存在せず、アクセス解析・広告SDK・トラッキングも入っていません。

2. 端末の中だけに保存される情報

  • 練習した動画の履歴・お気に入り・くり返し区間（購入者のみ・端末内にのみ保存）
  • 動画の題名は保存から30日を過ぎると自動的に消去されます（YouTube API Services 利用規約に基づく措置）

これらは端末の中だけにあり、外部へ送信されません。アプリを削除するとすべて消えます。

3. YouTube API Services の利用

本アプリは動画の再生に YouTube API Services（埋め込みプレーヤー）を使用しています。 動画の再生時には、YouTube／Google が利用規約とプライバシーポリシーに基づいて情報を取得することがあります。 詳しくは次をご覧ください。

  • YouTube 利用規約
  • Google プライバシーポリシー

4. 購入情報

フリコピパス（買い切り）の決済は Apple の App Store が処理します。開発者がクレジットカード情報等を受け取ることはありません。
